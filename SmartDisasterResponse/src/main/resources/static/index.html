03 · THE ENGINE

Four algorithms, one road graph.

Everything on this page is computed from the live graph by the same code the desktop tool runs — nothing here is canned.

A

Dijkstra

Costs every road as distance plus risk and traffic penalties, and treats blocked roads as impassable. It returns the cheapest evacuation route and drives the risk level and warnings shown with every result.

B

BFS · DFS

Breadth-first search counts the minimum number of roads between two points. Depth-first search answers reachability and finds the connected components — the isolated regions a disaster leaves behind.

C

Kruskal MST

Grows a minimum spanning tree over road distance with union-find: the smallest set of roads that keeps every location reachable — the backbone to keep open, clear or repair first.

    11 · FAQ

    How it works.

    What does Dijkstra's algorithm do here?

    It finds the cheapest evacuation route where a road's cost is distance plus risk and traffic penalties and blocked roads cost infinitely. Every route result shows cost, distance, risk level and any segment warnings.

    Why BFS for minimum roads?

    BFS explores level by level, so the first time it reaches a destination it has used the fewest roads — useful when junction count matters more than kilometres.

    What does DFS tell me in a disaster?

    DFS answers reachability: whether two locations are still connected at all, and which separate regions exist. After roads are blocked, components reveal isolated areas.

    What is the MST for?

    Kruskal's algorithm picks the smallest set of roads that keeps every location reachable at minimum total distance — the backbone to keep open, clear or repair first.
