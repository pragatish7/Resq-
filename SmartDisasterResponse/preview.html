⚙ Algorithms Explained

1. Dijkstra's Algorithm — Safest Evacuation Route

Finds the minimum-cost path where cost = distance + riskPenalty + trafficPenalty. Blocked roads return ∞ and are naturally excluded. Uses a Priority Queue to always expand the cheapest unvisited node.

Time: O((V + E) log V)  |  Space: O(V)

2. Breadth-First Search (BFS) — Minimum Roads

Explores level-by-level using a Queue. Guarantees the shortest path in terms of number of edges. Useful for finding minimum roads to traverse.

Time: O(V + E)  |  Space: O(V)

3. Depth-First Search (DFS) — Area Exploration

Goes as deep as possible before backtracking using a Stack. Checks connectivity, discovers all reachable areas, and finds connected components.

Time: O(V + E)  |  Space: O(V)

4. Kruskal's MST — Minimum Network

Sorts edges by weight, greedily adds shortest edges using Union-Find (path compression + union by rank) to avoid cycles. Produces V−1 edges connecting all locations at minimum total cost.

Time: O(E log E)  |  Space: O(V + E)

Cost Formula for Route Calculation

cost = distance + riskPenalty + trafficPenalty

  RiskPenalty:  LOW=0, MEDIUM=5, HIGH=10, VERY_HIGH=20
  StatusBonus:  BLOCKED→∞, DAMAGED→+5, HIGH_RISK→double risk
  TrafficPenalty: trafficLevel × 0.3

🚀 How to Run

Requirements

Java 17 or newer. No external dependencies needed.

Quick Start (one command)

cd SmartDisasterResponse
mkdir -p bin
javac -d bin src/model/*.java src/algorithms/*.java src/service/*.java src/ui/*.java src/Main.java
java -cp bin Main

Run Tests

javac -d bin src/model/*.java src/algorithms/*.java src/service/*.java tests/AlgorithmTests.java
java -cp bin AlgorithmTests
